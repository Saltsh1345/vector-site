# Vector — сайт центра восстановления (Самарканд)

Статический сайт без сборки. Публикуется через GitHub Pages из ветки `gh-pages` (держать равной `main`).

- `/` — вариант 1: светлый, первый экран с аркой «сад → дом».
- `/v2/` — вариант 2: первый экран на весь экран в подаче постов Instagram.
- `/v3/` — вариант 3 «Письмо»: по скиллу emergence-math (зерно 2196138754, колода 7f6452f9), стиль бренда Vector.
- `/v3/a/` — рабочая версия: утверждённый первый экран «Письмо» (ролик из фильмов центра) и страница в стиле Instagram бренда: мягкие формы фото вместо рам, переливающиеся кнопки, лицензия с документами, бесплатная консультация. Движение — движок scroll-craft (`vendor/scrollcraft/`, MIT).

Общие файлы: `img/`, `media/`, `docs/`, `brand/`. Пока страницы закрыты от поисковиков (`noindex`), это снимем, когда подключим домен.
