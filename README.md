# Vector — сайт центра восстановления (Самарканд)

Статический сайт без сборки. Публикуется через GitHub Pages из ветки `gh-pages` (держать равной `main`); домен клиента www.vectorecovery.uz — Vercel, `vercel.json` в корне.

- `/`, `/uz/`, `/tg/` — нынешняя страница («Письмо») на трёх языках: копии `/v3/a/…` с путями от корня, их пишет `.design/root.py` последним шагом сборки. Вручную не править — пересобираются из `/v3/a/`.
- `/v1/` — вариант 1: светлый, первый экран с аркой «сад → дом» (до 2026-11-02 лежал в корне).
- `/v2/` — вариант 2: первый экран на весь экран в подаче постов Instagram.
- `/v3/` — вариант 3 «Письмо»: по скиллу emergence-math (зерно 2196138754, колода 7f6452f9), стиль бренда Vector.
- `/v3/a/` — рабочая версия (источник копий в корне): утверждённый первый экран «Письмо» (ролик из фильмов центра), дальше письмо «шахматами» с фирменными лентами владельца (`brand/ribbon/`), тёмной и мятной полосами и рядом из трёх фото. Фото — WebP 480/800/1200 из оригиналов 4K (`img/c/`). Память проекта и палочка design-loop — `.design/`.
- `/v3/a/uz/` и `/v3/a/tg/` — то же письмо по-узбекски (латиница) и по-таджикски; шрифт текста Manrope Vector с таджикскими буквами (`brand/fonts/`, OFL).

Общие файлы: `img/`, `media/`, `docs/`, `brand/`. Пока страницы закрыты от поисковиков (`noindex`), это снимем, когда подключим домен.
