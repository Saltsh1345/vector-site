# Замысел

## 1. Кто и зачем
| Поле | Значение |
|---|---|
| Проект | Центр восстановления Vector, Самарканд (ООО «VECTOR-CLINIC», лицензия Минздрава РУз №1857962) |
| Для кого | Чаще родственники (мама, жена, сестра, взрослые дети); реже сам человек с зависимостью |
| Задача сайта | Звонок на дежурную линию или сообщение в Telegram, запись на бесплатную консультацию |
| Тон | Спокойно, без осуждения и давления, письмо от команды |
| Главное возражение | «Поставят на учёт, узнают, увезут силой, фото не настоящие» |

## 2. Устройство
- **Папка публикации:** корень репозитория `Saltsh1345/vector-site`, ветки `main` и `gh-pages` (GitHub Pages).
- **Форма путей:** `name/index.html`.
- **Стек:** статический HTML и CSS без сборки. Страница `/v3/a/` собирается скриптом из частей (первый экран утверждён и переносится без изменений).
- **Языки:** пока только русский. Узбекский, казахский и таджикский — в самом конце.
- **Предпросмотр:** своего `.claude/launch.json` нет. Проверка — `python3 -m http.server` из корня и Playwright Chromium.
- **Проверки проекта:** своих нет. Проверяем зондами среды по `design-loop/references/verification.md`.

## 4. Очередь
### Высокий приоритет
- Языки (узбекский латиницей, казахский, таджикский) и Manrope с недостающими буквами — по слову владельца «в самом конце».
- Адрес офиса — когда пришлёт владелец.

### Средний
- Форма «перезвоните мне» с доставкой заявки в Telegram (нужен бот или чат владельца).

- P3 (критика 2026-10-24): в первом экране 7 вариантов действия (3 в шапке, 3 кнопки, ссылка на лицензию). Instagram в первом экране — просьба владельца, оставлено.

### Идеи (только по слову заказчика)
- Перенести `/v3/a/` на главную, когда владелец утвердит.

## 5. Правила этого сайта
1. Не пересобирать страницы, отмеченные [x].
2. [x] ставится только после прошедшей проверки.
3. Первый экран «Письмо» с роликом А не трогать.
4. Все ссылки — на существующие файлы.
5. Фото только настоящие из фильмов центра. Дорисовка — только по прямому слову владельца.
